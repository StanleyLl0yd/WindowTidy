# Window Tidy 0.1.1

Acceptance: limited

## Changes

- Fixed loss of global hotkey registration when Settings is saved.
- Restored existing hotkeys after cancelling Settings; added native integration regression tests for Save and Cancel.
- Added Russian localization selected from the Windows display language; non-Russian systems use English.
- Added diagnostic display of all five hotkey registration states, received messages, target eligibility and Win32 errors.
- Distinguished arrow keys from numeric keypad keys by their virtual-key codes.
- Preserved the approved icon in the executable and tray.

## Owner verification

Owner confirmed on 2026-10-12 that all Window Tidy actions were verified and working on their actual Windows desktop after the fixes. The final hotkey diagnostic screenshot showed all five shortcuts registered, nonzero WM_HOTKEY event counts and eligible target windows. Evidence: [issue #10](https://github.com/StanleyLl0yd/WindowTidy/issues/10).

This is an owner-verified, **limited** device acceptance. The operating system build, full multi-monitor edge-case matrix and separate Windows 10 and Windows 11 results have **not** been recorded. [Issue #2](https://github.com/StanleyLl0yd/WindowTidy/issues/2) remains open for the full A01-A21 checklist.

## Packaging

Windows 10/11 x64, one portable unsigned EXE, no installer or external translation files, no third-party runtime dependencies. Windows may warn about an unsigned download. Verify the published SHA-256; do not disable security protections globally.
